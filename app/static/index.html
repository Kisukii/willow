Operator controls

Controls require the ADMIN_TOKEN configured on the server.

Monitoring configuration

Configure endpoints through the server’s MONITOR_TARGETS environment variable. Targets are operator-defined and cannot be changed by public visitors.

MONITOR_TARGETS=[{"id":"api","name":"My API","url":"https://your-service.example/health","kind":"live"}]

Default checks: HTTP 2xx = healthy; over 1,000 ms = degraded; non-2xx, timeout, DNS or TLS errors = unavailable. Redirects are not followed.
